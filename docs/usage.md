# TextSwitcher

Локальное приложение для macOS 13+ в строке меню. Без сервера, аккаунта, аналитики и сетевых запросов. Настройки сохраняются в UserDefaults.

Интерфейс следует языковым предпочтениям macOS, включая индивидуальный язык приложения в Системных настройках. Поддерживаются английский, русский, украинский, немецкий, французский, испанский, итальянский, португальский, польский, японский, корейский, упрощённый и традиционный китайский. Если подходящего перевода нет, используется английский. После изменения языка перезапустите приложение. Язык интерфейса не влияет на выбранные раскладки конвертации.

## Запуск

Готовое приложение: `dist/TextSwitcher.app`. Перенесите его в `~/Applications` или `/Applications` и откройте. При первом запуске включается автозапуск через системный Service Management; его можно отключить в настройках приложения.

Нажмите **Разрешить…** и включите TextSwitcher в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. Это системное разрешение нужно для чтения выделения и замены текста в других приложениях. После выдачи разрешения настройки обновляются автоматически; если macOS попросит перезапуск, закройте приложение через его меню и откройте снова.

- **Shift** — преобразовать выделенный текст; если выделения нет, преобразовать всё активное поле ввода.
- Подходит левый или правый Shift. Действие запускается при отпускании после короткого одиночного нажатия (до 0,75 с). Если вместе с Shift нажималась другая клавиша, кнопка мыши или выполнялась прокрутка, конвертация не запускается.
- Изменение сочетания: нажмите кнопку в настройках, затем нажмите и отпустите Shift или задайте другое сочетание. Esc отменяет запись. Обычные клавиши требуют ⌘, ⌃ или ⌥; F1–F20 можно назначать отдельно. На некоторых Mac функциональным клавишам требуется Fn.

Пример для обычной QWERTY и ЙЦУКЕН: `Ghbdtn Vbh` → `Привет Мир`; `Руддщ` → `Hello`. Если букву можно однозначно отнести к одной раскладке, направление выбирается для неё отдельно.

В списках доступны реальные клавиатурные раскладки, включённые в **Системные настройки → Клавиатура → Ввод текста → Источники ввода**. Данные о клавишах читаются из macOS, поэтому учитываются фонетические, Dvorak, AZERTY и пользовательские варианты. Выберите две разные раскладки. При добавлении или удалении источников список обновляется по системному уведомлению, а удалённый выбранный источник заменяется доступным. Конвертация не переключает текущую системную раскладку.

Если общая буква преобразуется по-разному в зависимости от направления, используется текущая системная раскладка: из неё — в другую выбранную. Если активна третья раскладка, приложение попросит переключиться на одну из выбранных. Общие буквы с одинаковыми соответствиями преобразуются без необходимости задавать направление. Русский и украинский теперь тоже можно выбирать парой.

Методы ввода с композицией (например, китайские и японские IME) не имеют прямой карты «клавиша → буква» и не предлагаются для конвертации; их названия показываются отдельным пояснением. Используются обычный, Shift и Caps Lock слои клавиатуры. Символы только через Option и комбинации мёртвых клавиш не восстанавливаются.

Меняются только пары «буква ↔ буква», включая верхний регистр. Цифры, пунктуация, пробелы, эмодзи и остальные символы сохраняются. Буква сохраняется, если соответствующая клавиша второй раскладки даёт знак, либо если она встречается на нескольких клавишах с разными буквенными соответствиями. Точный набор таких букв зависит от выбранных системных раскладок.

Замена выполняется через системные ⌘C / ⌘A / ⌘V, чтобы редактор мог отменить её через ⌘Z. Для Slack и других Electron-приложений включается дерево Accessibility через AXManualAccessibility. Прямое изменение AXValue не требуется. Для Sublime Text поддерживается версия 3 его метаданных буфера: копирование строки при пустом выделении распознаётся отдельно и запускает обработку всего документа. Неизвестные версии метаданных отклоняются, чтобы случайно не вставить копию строки поверх пустого выделения.

Буфер обмена временно используется и восстанавливается вместе с его типами данных; если пользователь успел поменять буфер после копирования, приложение отменяет вставку и не восстанавливает прежнее содержимое поверх нового. Собственные записи ограничены текущим Mac и помечены как временные и конфиденциальные для совместимых менеджеров буфера. После ⌘A выделение по возможности читается напрямую через Accessibility без ⌘C. Но общий буфер доступен другим локальным приложениям, а fallback-копирование в Sublime и других редакторах выполняется самим редактором: его записи могут попасть в историю или синхронизацию. Подробности — в [проверке безопасности](security.md). При замене форматированного текста отдельные стили могут не сохраниться. Некоторые нестандартные редакторы не предоставляют достаточного доступа; в таком случае приложение показывает сообщение об ошибке, не забирая фокус. Поля, обозначенные как парольные в Accessibility, и режим Secure Event Input исключены; произвольное поле с секретом без такой маркировки приложение распознать не может.

После локальной пересборки ad hoc подпись меняется. Если macOS отозвала Универсальный доступ, удалите TextSwitcher из списка разрешений, добавьте установленную копию снова и перезапустите приложение.

## Сборка и проверка

```sh
swift test
zsh scripts/build.sh
open dist/TextSwitcher.app
```

Используются только системные фреймворки AppKit, SwiftUI, Carbon, ApplicationServices и ServiceManagement. Внешних зависимостей нет. Сборка включает Hardened Runtime и локально подписана ad hoc. Публичный ZIP доступен в GitHub Releases; подписи Developer ID и нотарификации Apple пока нет, поэтому первый запуск может потребовать разрешения в настройках безопасности macOS.
